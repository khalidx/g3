# g3

A collection of plugins for git.

## Setup

```bash
git clone https://github.com/khalidx/g3.git
```

Then add the following to your ~/.bash_profile (or ~/.zshrc, or whatever profile file you use):

```bash
export PATH="path/to/git-plugins/bin:$PATH"
```

For example, after cloning you could:

```bash
cd g3/
export PATH="$(pwd)/bin:$PATH"
```
